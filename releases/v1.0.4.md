## What's new

- **Carry-over now takes care of itself.** Each month's carry-over is always last month's leftover — automatically. Change anything in an earlier month (add a transaction, fix an amount, import old bank rows) and every later month's carry-over updates on its own. Before, those numbers were frozen the moment you started the next month and could quietly drift out of sync.
- **A one-time check of your history.** The first time you open this version, the app re-checks every month's carry-over and fixes anything that drifted, then shows you exactly what it corrected. Tiny penny-rounding corrections are tucked behind a single line so anything real stands out.
- **Carry-over can't be typed over anymore.** It's shown as a plain number with a note telling you which month it comes from — if it looks wrong, fix last month and it follows. The one exception: a fund's very first month (the app's first month, or a fund you add mid-year) still lets you type its opening balance, marked "opening."
- **Importing older transactions is called out.** If a bank file includes rows dated in a month you've already moved past, the import preview says so up front — those rows post to the month the bank says, and the newer months' carry-overs follow automatically. The rows get an "earlier month" tag so nothing slips in unnoticed.
