## What's new

- **A backup you can always go back to.** Whenever an update changes how your data is stored, the app now keeps one copy of your file from just before the change. It shows up in **Settings → Restore** as "saved before the v7 update", and it's never cleaned up automatically — neither are the "saved before a restore" copies. If an update ever needs to be undone, that file is the way back.
- **Small fixes under the hood** to how releases are checked and published, so the in-app update check always finds what it expects.
- **Groundwork for the Mac version.** Nothing to see on Windows yet.
